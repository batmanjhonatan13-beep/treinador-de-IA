Exportar

Monta uma pasta com o conhecimento treinado + o script que o roda em qualquer máquina. Só entra aqui o que está consolidado (🟢) — texto pela prova automática, classificador pelo acerto em imagens nunca vistas, estilo de imagem pelo seu julgamento.

Montar pacote

Escolha um conhecimento consolidado. Para um pacote com dois assuntos, treine os dois arquivos juntos na página Treino (juntar pesos já treinados não funciona). O pacote leva os pesos, um run.py, o README e o instalador com os pacotes certos do sistema escolhido (Ubuntu, Amazon Linux 2023 ou 2, SUSE, RHEL, Alpine, macOS ou Windows).

Servidor com vários modelos (o pacote com roteador)

Marque tudo que precisa ir para a mesma máquina — a doc que virou peso, o estilo de imagem, o som, o classificador, o 3D. Sai uma pasta com cada peça na sua subpasta mais um roteador: sobe com ./subir.sh e atende tudo num endereço só, no formato da OpenAI.

As peças ficam desligadas até alguém pedir e voltam a dormir depois de 5 minutos paradas. Uma peça de GPU por vez — numa placa só não cabe tudo junto, então o roteador tira uma para pôr a outra. Quem só precisa de memória (classificadores) não disputa a placa. Vai junto um API.md com cada chamada documentada, para quem quiser escrever uma ferramenta em cima do seu modelo.

Isto não é fusão. Dois conhecimentos de texto no mesmo pacote continuam carregando um de cada vez: juntar adaptadores já treinados foi medido aqui e piora o resultado. Para os dois assuntos numa resposta só, treine os arquivos juntos na página Treino.
